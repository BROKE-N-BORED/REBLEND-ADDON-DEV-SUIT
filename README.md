Phase 5: the Blender test window (`blender_test_window.py`, §8.3), opened from the same menu. Phase 6: the command palette (`palette.py`, §6.10, Ctrl+K), opened from the chat window; the How to Use window (`help_window.py`, §6.10, U22), opened from the Help menu.
  - `blender_drive/` — Phase 5: the Blender drive backend (`runner.py` + `scripts.py`, §8.3). `python3 -m devsuite.main` opens the chat window standalone.
  - `update/` — the silent update check + ask-first auto-update (`check.py` asks GitHub's public releases endpoint for the latest Release, `apply.py` pulls the release zip + `.sha256` sidecar, verifies the checksum before installing, runs the extracted tree's own installer in a subprocess reusing the venv, and restarts on Yes; §9.7).
- `pyproject.toml` — the package (name `reblend-addon-dev-suite`, version 0.1.0, PySide6 a core dependency, console script `devsuite`); the templates ship as package data (their files are not in packages, so setuptools would drop them otherwise).
- `installer/` — Phase 6: the suite's own GUI installer (`install.py`, headless stdlib logic — venv, pip install, menu launchers (app + Uninstall), verify-before-success — plus a CLI; `gui.py`, the tkinter window, stdlib only so it runs before PySide6 exists; `uninstall.py`, the uninstaller — removes the install folder and both menu launchers, and the app data only when asked — plus the Uninstall window in `gui.py`, also runnable on its own as the `devsuite-uninstall` console script). Shipped inside the installed package, so the Uninstall menu entry works after the release tree is deleted.
- `Install Reblend Add-on Dev Suite.desktop` — the double-click installer launcher (python3 -c `%k` pattern, Terminal=false). `install.sh` — the bash terminal fallback for the same steps. `uninstall.sh` — the bash uninstall front end (confirms first, default No). `run.sh` — the tree launcher (§9.1): runs the installed suite when there is one, else the tree's copy.
- `tests/` — stdlib unittest tests for the suite code. Run them from this folder:
  - Stdlib suite: `python3 -m unittest discover -s tests` (the Qt test module skips cleanly where PySide6 is absent).
  - Full suite incl. Qt: `LD_LIBRARY_PATH=$HOME/workspace/qt-libs/root/usr/lib/x86_64-linux-gnu __EGL_VENDOR_LIBRARY_DIRS=$HOME/workspace/qt-libs/root/usr/share/glvnd/egl_vendor.d QT_QPA_PLATFORM=offscreen TMPDIR=/tmp ~/workspace/tmp/qt-venv/bin/python -m unittest discover -s tests` (PySide6 6.12.0; the EGL env is a sandbox quirk — his PC has system Qt libs. Never override HOME for Qt runs.)
